# Imtera Test


## Локальный деплой

1. Загрузить код
   `git clone ...`

2. В директории проекта прописать переменные окружения (описаны ниже) в файле `.env` (создать либо скопировать из `.env.example`)

3. Запустить контейнер
   `docker compose up -d`

После сборки и запуска контейнеров необходимо подождать 1-3 минуты, пока выполняются необходимые скрипты (миграции, установка браузеров и т.п.)

Сид-пользователь:
```
логин: user@imtera.ru
пароль: secret
```

## Переменные окружения

- `CACHE_ORGANIZATION_TTL` - срок жизни сведений об организации в кеше

Остальные переменные можно не менять


## Подход к парсингу
После нескольких попыток работы с API был принят подход парсинга страницы - разбор на элементы с определёнными классами.
Принцип: headless браузер проходит по указанному url, собирает общие данные (наименование, рейтинг и т.п.), затем открывает url организации с отзывами, прокручивает панель вниз, пока элементы не перестанут подгружаться после нескольких прокруток и парсирует все отзывы в кеш.
По запросу с фронта отдаётся вся полная информация.
